# HDB v6.2 — Pre-test instructions and Data Collection return

UX changes:
- Cognitive test opens a full instruction screen before Reaction Time / Go-No-Go / Adaptive Go-No-Go.
- Tapping test opens instructions before either 15-second hand trial.
- Memory Check opens instructions before the 8-item sequence.
- No timed/scored stimulus begins until the participant presses START.
- A participant can return to Data Collection from the instruction screen without starting a session.
- After a completed test is saved, HDB returns directly to Data Collection and displays a saved-session confirmation banner.

Protocol content is otherwise unchanged from v6.1:
- Memory form remains v6.1 (4 check-up + 2 recall + 2 challenge).
- Tapping and cognitive task rules are unchanged.
