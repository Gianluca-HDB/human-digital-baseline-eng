LONGITUDINAL FUNCTION

Neuro Function Log

Track changes in memory, gait, motor function, daily function and selected non-motor features over time.

Not an Alzheimer/Parkinson diagnostic test. These features are nonspecific and can have many causes. The purpose is longitudinal change detection and correlation with the independent cognitive battery.

Observation window: past 7 daysFor non-countable symptoms, record on how many days the symptom was present: 0 = 0 days; 1 = 1–2 days; 2 = 3–4 days; 3 = 5–7 days. Falls and trips/near-falls remain exact numeric counts.

Operational definitions — always use the same criteria

FallCount 1 event when you unintentionally come to rest on the ground, floor, or another lower level. Exact count.
Trip / near-fallCount 1 event when balance is lost or you trip but recover without reaching the ground or a lower level. Exact count.
Recent-memory lapsePositive day if recent information/event is forgotten and a reminder or repetition is needed.
Word findingPositive day if a familiar word cannot be retrieved and must be replaced, described, or supplied.
Missed task/appointmentPositive day if a planned activity is forgotten without an external reminder.
Misplaced objectPositive day if an everyday object is put in an unexpected place and its location cannot be promptly retraced.
PlanningPositive day if a familiar multi-step activity needs help, repetition, or more attempts than usual.
DisorientationPositive day if date, place, or familiar route is mistaken and correction or guidance is required.
Conversation / readingPositive day if the thread is lost and rereading or repetition is required for comprehension.
Motor slownessPositive day if a familiar motor activity is clearly slower than personal usual performance.
StiffnessPositive day if stiffness changes at least one usual movement or activity.
TremorPositive day if visible tremor occurs at rest or during an action, excluding external vibration.
Fine motorPositive day if buttons, handwriting, or another fine-motor task takes more attempts or time than usual.
Gait changePositive day if shorter steps, dragging, or another evident gait change occurs versus personal usual.
Freezing-likePositive day if, while intending to start or continue walking, the feet temporarily seem unable to initiate movement.
Chair risePositive day if more attempts, new arm use, or assistance is required versus usual.
SmellPositive day if familiar odors normally perceived are clearly less noticeable under comparable conditions.
Constipation changePositive day if bowel pattern differs from personal usual; record obvious context factors in Context Log.
Sleep movement/vocalizationPositive day only when reported by an observer or recalled as motor/vocal behavior during sleep.
Daytime sleepinessPositive day if unintended sleepiness occurs during an activity normally performed awake.
Standing light-headednessPositive day if dizziness/faintness follows standing; orthostatic blood pressure remains separate in Vitals.
Urinary urgency/frequencyPositive day only for a new change versus personal usual baseline.
SwallowingPositive day if food/liquid causes coughing, sticking sensation, or repeated swallowing attempts.
Softer voicePositive day if self or observer notices a softer-than-usual voice under comparable conditions.
Daily activitiesPositive day if a usual personal/household activity needs new assistance or is not completed as usual.
Driving / navigationPositive day if a new error occurs on a familiar route or navigation task.
InitiativePositive day if a usual planned activity is not initiated despite time and opportunity.
Mood / behaviorPositive day only for an observable change versus personal usual, reported by self or observer.
Visual perceptionsPositive day if a person/object/animal is clearly reported as seen despite not being present; this is not a diagnosis.

Rule: Common rule: for symptoms, count positive days, not total episodes within a day. Use 0, 1–2, 3–4, or 5–7 days. Falls and near-falls remain exact event counts.
